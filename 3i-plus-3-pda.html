PDA for L = {ai bk : i, k > 0 and k = 3i + 3}

This Push-Down Automaton (PDA) recognizes the language L = {ai bk : i, k > 0 and k = 3i + 3}, which represents strings with i 'a's followed by k 'b's, where k = 3i + 3.

For each 'a' read, the automaton pushes three X's onto the stack. When the first 'b' is encountered, it pushes three more X's (for the +3 part of the formula), then transitions to a state that pops one X for each 'b' read.

Examples of strings in the language:

  • For i=1: "abbbbbb" (1 'a' followed by 6 'b's, since 3×1+3=6)
  • For i=2: "aabbbbbbbbb" (2 'a's followed by 9 'b's, since 3×2+3=9)
  • For i=3: "aaabbbbbbbbbbbb" (3 'a's followed by 12 'b's, since 3×3+3=12)

Input Tape:

Transition label format: input/pop/push

• a - Input symbol 'a'
• b - Input symbol 'b'
• X - Stack symbol
• ε - Empty string (no operation)
