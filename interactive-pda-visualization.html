Interactive Push-Down Automaton Visualization

This Push-Down Automaton recognizes the language L = {anbn | n ≥ 1}, which represents strings with equal numbers of 'a's followed by an equal number of 'b's.

The automaton uses a stack to keep track of the number of 'a's seen before starting to read 'b's, and then pops one element for each 'b' encountered. If the stack empties exactly when the input is consumed, the string is accepted.
